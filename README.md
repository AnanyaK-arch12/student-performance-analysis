# Student Performance Analysis

## Overview
A beginner-friendly data analysis project using Python and Pandas to analyze student marks and attendance.

## Features
- Displays student data using a Pandas DataFrame.
- Calculates the total number of students.
- Calculates average marks and attendance.
- Categorizes students based on marks.
- Identifies the topper and lowest scorer.

## Technologies Used
- Python
- Pandas

## How to Run
Install Pandas:

```bash
py -m pip install pandas
```

Run the project:

```bash
py project.py
```

## Learning Outcomes
Practiced DataFrames, statistical calculations, conditional logic, and basic data analysis using Pandas.
